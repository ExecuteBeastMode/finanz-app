# Finanz-App

Mobile-first Finanz-Tracker als PWA. Daten bleiben lokal im Browser (localStorage), kein Server, keine Werbung.

## Funktionen
- Einnahmen und Ausgaben eintragen
- Kategorien, Monatsnavigation, Saldo
- Ausgaben nach Kategorie als Balken
- CSV-Export, Offline nutzbar

## Auf dem iPhone installieren
1. Repo-Settings > Pages > Branch `main` / Root aktivieren
2. Die Seite `https://<user>.github.io/finanz-app/` in Safari öffnen
3. Teilen > Zum Home-Bildschirm
